# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project uses [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added
- Save YouTube videos to My List and play them with the same Netflix-style controls.
- Add videos from your own computer to My List.
- Subtitle support.
- Profiles, so each person gets their own My List.
- First-run guidance, a "how to save" guide in My List and a bundled demo clip.

### Changed
- My List has been redesigned in a Netflix-style layout.
- The "Play a file" screen now matches the My List look.
- Long titles, file names and channel names are truncated cleanly in My List.

## [1.4.0]

### Added
- My List for videos saved from X: every post with a video gets a "My List" button.
- Saved videos appear in a Netflix-style list in the player page and play back to back.

## [1.3.0]

### Added
- Video preview on the seek bar.
- Editable, nicely formatted video titles in the info overlay.
- Pre-roll and post-roll branding clips, with controls to pick the intro theme or hide them.
